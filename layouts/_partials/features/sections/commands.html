:cTab commands

A tab manager you run by typing. Clean up a messy tab bar in one command.

There's no dashboard to open. Type what you want done and press Enter. Tab commands work on every tab in the window, or across all your windows.

  • Close duplicate tabs across every window
  • Close tabs to the left, to the right, or all other tabs
  • Merge all windows into one
  • Suspend inactive tabs to free up memory
  • Sort tabs alphabetically, mute or reload them all
