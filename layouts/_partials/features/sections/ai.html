:aiAI chat

Ask AI from any page. With your own API key.

Type :ai and chat inside the palette. Add @page to your message and the page you're on goes along with it, so you can summarize, translate or question it without copying a word.

  • Nine providers. ChatGPT, Claude, Gemini, Grok, Groq, DeepSeek, Mistral, Perplexity and any model on OpenRouter. Switch between them in the palette.

  • Straight to the provider. Messages go from your browser to the provider with your key. There is no TabCmdr server in between.

  • Presets and history. Save custom presets, and each provider or preset keeps its own chat history.
