## Opening & Closing the Palette

| Shortcut | Action |
|---|---|
| `⌘ K` (macOS) / `Ctrl K` (Windows/Linux) | Open the command palette |
| `Escape` | Close the palette |
| Click outside the palette | Close the palette |

## Navigating Results

| Shortcut | Action |
|---|---|
| `↑` / `↓` | Move up or down through results |
| `Enter` | Execute the selected item |
| `Tab` | Move to the next result (alternative to `↓`) |

## Inside the Palette

| Shortcut | Action |
|---|---|
| Type anything | Filter results instantly |
| Type a math expression | Show calculator result (e.g., `12 * 8`) |

## Changing the Shortcut

The default shortcut is `⌘ K` / `Ctrl K`. If this conflicts with a site you use, you have two options:

1. **Disable TabCmdr on that domain** — add the domain to your Disabled Domains list in Settings. The shortcut won't fire on that site.
2. **Change the extension shortcut** — go to your browser's extension keyboard shortcut settings:
   - **Chrome:** `chrome://extensions/shortcuts`
   - **Firefox:** `about:addons` → gear icon → Manage Extension Shortcuts
