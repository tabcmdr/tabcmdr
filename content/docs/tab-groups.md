## Overview

TabCmdr supports Chrome's tab groups feature, letting you create, manage, and organize tab groups directly from the palette.

> **Note:** Tab groups are a Chrome-only feature. This permission is not requested on Firefox.

## Enabling Tab Groups

1. Open the TabCmdr **Settings** page.
2. Find the **Tab Groups** toggle and turn it on.
3. Confirm the permission in the browser prompt.

## What You Can Do

| Action | Description |
|---|---|
| View group membership | See which group a tab belongs to in search results |
| Create a tab group | Group selected tabs together with a name and color |
| Rename a group | Change the name of an existing group |
| Change group color | Update the color label of a group |
| Move tabs between groups | Reorganize tabs across groups |
| Ungroup tabs | Remove tabs from a group |

## How to Use

Open the palette and search for "group" to see all available tab group commands. Select the action you want and follow the prompts.

## Privacy

Tab group data (names, colors, membership) is only accessed while the palette is open and is never stored or transmitted.
