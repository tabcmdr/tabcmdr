## Overview

TabCmdr gives you quick access to your recent downloads from the palette. Search, open, or remove downloaded files without opening the browser's downloads page.

## Enabling Downloads

Downloads access requires an optional permission. To enable it:

1. Open the TabCmdr **Settings** page.
2. Find the **Downloads** toggle and turn it on.
3. Confirm the permission in the browser prompt.

## What You Can Do

| Action | How |
|---|---|
| Search downloads | Type a filename or URL in the palette |
| Open a downloaded file | Select it and press **`Enter`** |
| Remove from list | Select it and choose "Remove from list" |

## What Each Result Shows

- **Filename** - the name of the downloaded file
- **Source URL** - where the file was downloaded from
- **File size** - how large the file is
- **State** - whether the download is complete, in progress, or interrupted

## Privacy

Download data is loaded into memory while the palette is open and discarded when you close it. TabCmdr never stores download information or sends it anywhere.
