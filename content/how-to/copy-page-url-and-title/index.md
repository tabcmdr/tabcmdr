## Chrome's built-in way to copy the address {.way-chrome}

1. Press {{< kbd "Ctrl" "L" >}}, {{< kbd "Alt" "D" >}} or {{< kbd "F6" >}} on Windows and Linux, or {{< kbd "⌘" "L" >}} on a Mac, to jump to the address bar.
2. Press {{< kbd "Ctrl" "C" >}} ({{< kbd "⌘" "C" >}} on a Mac) to copy the address.

Source: Google's [Chrome keyboard shortcuts](https://support.google.com/chrome/answer/157179), Microsoft's [Windows keyboard shortcuts](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec) and Apple's [Mac keyboard shortcuts](https://support.apple.com/en-us/102650) pages, checked in October 2026.

## Copy the URL or title with TabCmdr {.way-tabcmdr}

TabCmdr is a keyboard launcher that lives in your browser. From its search box you can copy the address or the title of the page you're on, or the address of any other open tab.

**Before you start:** add [TabCmdr from the Chrome Web Store](https://chromewebstore.google.com/detail/ejkkibnhfeccfnofeimpialoaipkojdc). It has a 7-day free trial and needs no account.

### Copy the address of the page you're on

Press {{< kbd "⌘" "K" >}} on a Mac or {{< kbd "Ctrl" "K" >}} on Windows and Linux, type `copy url` and press {{< kbd "Enter" >}} on **Copy Page URL**. The palette closes, **URL copied** shows at the bottom of the page, and the full address is on your clipboard, including anything after `?` or `#`.

{{< screenshot src="copy-page-url-command.png" alt="TabCmdr palette with copy url typed and the Copy Page URL command highlighted" caption="`copy url` finds Copy Page URL." >}}

### Copy the page title

Type `copy title` and press {{< kbd "Enter" >}} on **Copy Page Title**. **Title copied** shows at the bottom of the page. It copies the title you see on the tab, which makes a handy label when you paste a link into notes or a chat.

{{< screenshot src="copy-page-title-command.png" alt="TabCmdr palette with copy title typed and the Copy Page Title command highlighted" caption="`copy title` finds Copy Page Title." >}}

### Copy the address of another tab

You don't have to switch tabs first. Type a few letters of the tab's title, then point at the highlighted row and click the link button. A **Copy URL** label shows when you point at it. The palette stays open and shows **URL copied**, so you can copy another one or press {{< kbd "Esc" >}} to close it.

{{< screenshot src="copy-url-row-button.png" alt="TabCmdr palette with pull typed, the GitHub tab highlighted, its Copy URL button labelled and a URL copied message" caption="The link button on a tab's row copies that tab's address." >}}

Bookmark and history rows have the same button.
