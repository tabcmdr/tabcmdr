## Change the theme in TabCmdr {.way-tabcmdr}

TabCmdr is a keyboard launcher that lives in your browser. Its palette has 28 color themes, many of them named after popular code editor themes.

**Before you start:** add [TabCmdr from the Chrome Web Store](https://chromewebstore.google.com/detail/ejkkibnhfeccfnofeimpialoaipkojdc). It has a 7-day free trial and needs no account.

### Step 1: Open TabCmdr Settings

Press {{< kbd "⌘" "K" >}} on a Mac or {{< kbd "Ctrl" "K" >}} on Windows and Linux, type `settings` and press {{< kbd "Enter" >}} on **TabCmdr Settings**.

### Step 2: Choose Appearance

Pick **Appearance** in the sidebar. The **Theme** grid shows a small preview of each theme, grouped into Dark and Light. The name of the theme you're using sits next to the **Theme** label.

{{< screenshot src="theme-appearance-grid.png" alt="TabCmdr settings on Appearance, showing the Theme grid with System selected and the dark themes listed" caption="System is selected. The All, Dark and Light buttons filter the grid." >}}

### Step 3: Click a theme

Click any theme to use it. The setting saves straight away, and the next time you open the palette it uses the new colors.

{{< screenshot src="theme-dracula-palette.png" alt="TabCmdr palette in the Dracula theme with results for pull" caption="The palette in Dracula." >}}

{{< screenshot src="theme-solarized-light-palette.png" alt="TabCmdr palette in the Solarized Light theme with results for pull" caption="The same search in Solarized Light." >}}

## Every theme you can pick {.way-tabcmdr}

| Group | Themes |
|---|---|
| Dark (16) | Dark, Midnight, Rosé Pine, Catppuccin, Dracula, Nord, Tokyo Night, Gruvbox, One Dark, Monokai, Solarized Dark, Palenight, Kanagawa, Everforest, Night Owl, Ayu Dark |
| Light (12) | Light, Solarized, Latte, Rosé Dawn, Gruvbox Light, Nord Light, One Light, Everforest Light, Ayu Light, Tomorrow, Material Light, GitHub Light |

**System** is the default. It uses Dark when your computer is in dark mode and Light when it isn't.
